# 🌸 Femora – Period Tracker

**Femora** is a simple, elegant, and mobile-friendly period tracking website designed to help women track their menstrual cycles, monitor period history, and view upcoming period predictions.

Built with a soft feminine design and a simple interface, Femora makes period tracking easy and convenient.

## ✨ Features

- 🩷 **Period Tracking** – Record period start dates and times.
- 📅 **Automatic End Date** – Automatically estimate when your period will end.
- 🔄 **Cycle Tracking** – Calculate cycle length using previous records.
- 🔮 **Next Period Prediction** – Estimate your upcoming period date.
- 🗓️ **Calendar View** – View period dates and upcoming cycles.
- 📖 **Period History** – View, edit, and delete previous records.
- 📊 **Cycle Statistics** – Track cycle length and period duration.
- 💾 **Local Storage** – Save your tracking data directly in your browser.
- 📱 **Responsive Design** – Designed for mobile devices and desktops.
